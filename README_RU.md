# Практическая часть дипломной работы: минимальный MQTT-брокер на C

Этот архив содержит собранную практическую часть по серии материалов **MQTT broker from scratch**. Внутри находится рабочий код минимального MQTT 3.1.1 брокера, русская инструкция по сборке/запуску, конспект с переводом технического содержания и исходные тексты, на основе которых выполнена работа.

## Что реализовано

Брокер `sol-broker` — однопроцессный TCP-сервер на C для Linux/Unix-подобной среды. Он поддерживает базовые MQTT 3.1.1 операции:

- `CONNECT` → `CONNACK`;
- `SUBSCRIBE` → `SUBACK`;
- `UNSUBSCRIBE` → `UNSUBACK`;
- `PUBLISH` с QoS 0 и входящим QoS 1/2;
- `PUBACK`, `PUBREC`, `PUBREL`, `PUBCOMP` для базовой QoS-логики;
- `PINGREQ` → `PINGRESP`;
- `DISCONNECT`;
- wildcard topics: `+` и `#`;
- retained messages для публикаций с retain-флагом.

Проект сделан как минимальный учебно-демонстрационный брокер. Он подходит для дипломной практической части, тестирования через `mosquitto_pub/mosquitto_sub` и демонстрации принципов MQTT, но не заменяет production-брокеры уровня Mosquitto, EMQX или HiveMQ.

## Быстрый запуск

```bash
cd mqtt_broker_diploma
./build.sh
./sol-broker 0.0.0.0 1883
```

Проверка встроенным тестом:

```bash
python3 -S tests/integration_test.py
```

Проверка через MQTT-клиенты:

```bash
# Терминал 1
./sol-broker 127.0.0.1 1883

# Терминал 2
mosquitto_sub -h 127.0.0.1 -p 1883 -t 'diploma/#'

# Терминал 3
mosquitto_pub -h 127.0.0.1 -p 1883 -t 'diploma/demo' -m 'hello from diploma'
```

## Примечание по соответствию исходным материалам

Исходная серия статей разбита на шесть технических частей: протокол, сетевой модуль, сервер, структуры данных, topic abstraction и handlers. В этом архиве эти задачи сведены в единый компилируемый проект. Для надежности и компактности учебной реализации серверный цикл использует `select()`, а не `epoll`, но архитектурно выполняет ту же роль: принимает TCP-клиентов, читает MQTT-пакеты, вызывает обработчик по типу команды и отправляет ответ.
